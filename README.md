# Drone-PUR project page

This is a self-contained academic project website. It uses plain HTML, CSS and JavaScript; no build step or external CDN is required.

## Files

- `dist/index.html`: title, authors, introduction, benchmark, model and citation.
- `dist/styles.css`: responsive desktop, tablet and phone styles.
- `dist/site-config.js`: the five resource destinations, kept in one place.
- `dist/cases.js`: the 11 original task examples with images, questions and reference answers.
- `dist/app.js`: case navigation, answer reveal, image viewer, resource dialogs and citation copying.
- `dist/assets/`: real figures and example images extracted from the supplied latest paper, plus the manuscript PDF.

## Update the resource buttons

Edit `dist/site-config.js`. The five independent entries are Paper (arXiv), Code (GitHub), Model weights (ModelScope), Benchmark (ModelScope), and Training source (ModelScope). Replace each `url: null` with the verified release URL. The resource becomes a direct link automatically; update `badge` to change its label. No release URLs have been invented. The arXiv button currently opens release information with a working link to the bundled manuscript PDF.

## Publish at https://drone-pur.github.io/

GitHub reserves this root address for the `drone-pur` user or organization. You must own that account or have permission to manage its Pages repository.

1. Under the `drone-pur` account or organization, create or use the repository `drone-pur.github.io`.
2. Put **the contents of `dist/`** in the repository root: `index.html`, `styles.css`, `site-config.js`, `cases.js`, `app.js`, `.nojekyll`, and `assets/`.
3. In GitHub, open **Settings → Pages → Build and deployment**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, and save.
5. Wait for the Pages deployment to finish. The project homepage will use the requested URL.

The separately provided GitHub Pages ZIP already has this flat root layout; upload its extracted contents. Do not upload the ZIP file itself.

GitHub documentation: https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages

## Content and provenance

- Content follows `Drone_PUR__Trans_ (38)(2).pdf`, provided by the author.
- Author names and sample counts follow the supplied manuscript. Affiliations include subsequent author-provided updates: Jiekang Feng also lists Xiong’an Guochuang Lantian Technology Company Ltd.; Xingyue Guo also lists Nanyang Technological University.
- Task images, question content and reference answers come from Figure 2. The MIG prompt uses “marked box” instead of a color-specific reference for clarity; coordinates and task meaning are preserved.
- Figures are reused from the paper. No experimental plots, scores or sample images were generated by AI.
- The layout is inspired by the restrained academic structure of MM-UAVBench and DualVision, with platform badges based on the supplied reference; the website code is newly written.
- The citation is a project-level `@misc` entry, not a claim of journal acceptance or publication. Update it when publication metadata becomes available.

## Local viewing

Serve `dist/` with any static HTTP server, for example `python -m http.server 8000 --directory dist`, then open `http://localhost:8000/`.

## Validation

JavaScript syntax, asset references, task count, answer-reveal state, all eleven task transitions, image enlargement, citation copying and responsive layouts were checked. The site has no form submissions, analytics or server dependency.

## Simplified edition

Removed the hero tagline, numbered section labels, redundant helper text, data construction section and findings section. Dataset statistics are displayed directly beneath the task overview. Existing case navigation, answer reveal, image zoom and citation copying remain available.

Task labels in the capability overview and example controls use full names only. The dataset statistics caption is the original Figure 4 title: “Statistical overview of the Drone-PUR dataset.”
