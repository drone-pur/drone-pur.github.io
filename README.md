# Drone-PUR

**From Visual Clue Discovery to Understanding and Reasoning in UAV Scenes**

Official project website for Drone-PUR, a UAV dataset and benchmark covering 11 tasks across perception, understanding, and reasoning. We also introduce UAV-PUR, a simple baseline for studying joint domain adaptation across these tasks.

- [Project page](https://drone-pur.github.io/)
- [Paper](https://arxiv.org/abs/2610.40801)
- [Benchmark](https://huggingface.co/datasets/Henard224/Drone-PUR-Benchmark)

The website presents the benchmark, dataset statistics, interactive samples, the UAV-PUR baseline, and model results. Training resources and model weights will be released on Hugging Face.

To update the website, edit `index.html` for page content, `cases.js` for samples, and `site-config.js` for resource links.
